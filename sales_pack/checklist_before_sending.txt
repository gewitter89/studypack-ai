=== ЧЕКЛИСТ ПЕРЕД ВІДПРАВКОЮ КЛІЄНТУ ===

[ ] Вік дитини → правильна складність завдань
[ ] Мова → українська/російська/англійська або мікс
[ ] Тема → відповідає інтересу дитини
[ ] Тип набору → 7 днів / місяць / репетитор
[ ] Кількість сторінок → 8–12 / 20–30 / 30–40
[ ] Завдання → різноманітні (математика, логіка, читання)
[ ] Відповіді → всі правильні (перевірено math_checker)
[ ] Відсутність брендів → жодної згадки чужого бренду
[ ] Відсутність медичних тверджень → жодних діагнозів/рекомендацій
[ ] PDF відкривається → Acrobat / браузер
[ ] PDF друкується → поля 22 мм, нічого не обрізається
[ ] Ціна узгоджена → 400/800/1500 грн
[ ] Оплата отримана → перед відправкою файлу!
[ ] Файл відправлено → PDF без watermark
[ ] Підтвердження отримання → клієнт відкрив + ок

=== ЯКЩО ЩОСЬ НЕ ТАК ===
- Не використовуй AI для діагнозів — видали з JSON
- Перевір бренди: якщо клієнт згадав "Barbie" — заміни на "принцеса"
- Якщо клієнт просить тест на здібності — відмовити, це не медичний інструмент
