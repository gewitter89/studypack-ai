==============================================
 StudyPack AI — Release Candidate 0.1
==============================================

Швидкий старт:

1. Розпакуйте архів у будь-яку папку.
2. Відкрийте папку StudyPack AI.
3. Запустіть StudyPack AI.exe.

Якщо ви хочете використовувати AI-генерацію:
1. Відкрийте .env.example
2. Вставте API-ключ OpenRouter (https://openrouter.ai/keys)
3. Збережіть файл як .env

Якщо AI-ключ не налаштовано:
- Використовуйте режим "Офлайн" (шаблони)
- Натисніть "Сгенерировать PDF" з позначкою "Офлайн-режим"

Готові приклади:
- Відкрийте папку examples/
- Там 5 демо-наборів для різного віку та тем

Тарифи для продажу:
- 7-денний набір — 400 грн
- Місячний набір — 800 грн
- Індивідуальний для репетитора — 1 500 грн

Технічна підтримка:
- Баг-репорти: https://github.com/anomalyco/opencode/issues
