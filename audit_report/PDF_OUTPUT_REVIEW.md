## 2. Generator Codebase Quality Audit

We reviewed the files `core/card_generator.py`, `core/card_text_gen.py`, `core/topic_injector.py`, `core/topic_lexicon.py`, `core/language_layer.py`, `core/instruction_variety.py`, `core/editorial_pass.py`, `core/quality_gate.py`, and `pdf/renderer.py`.

### 1. Where are tasks generated?
*   **Offline Mode**: Generated in `core/card_text_gen.py` via individual generators (e.g. `gen_shape_find`, `gen_story_read`, etc.) and mapped to presets in `core/templates.py`.
*   **Online Mode**: Generated by OpenRouter LLM clients using prompts defined in `prompts/generate_pack.md`.

### 2. Is there hardcoded Russian text?
Yes.
*   `core/card_text_gen.py` contains hardcoded Russian text blocks for many task fallbacks.
*   `templates_library/presets/` files contain hardcoded `"grade": "Дошкольник"`, which is parsed by `core/templates.py` and written to the final output file metadata. If language translation fails or is skipped, this Russian label leaks into Ukrainian sheets.
*   `core/card_text_gen.py` shape generators contain Cyrillic `"о"` as a representation for circle tasks:
    ```python
    ru_shapes = [("круг", "о"), ("квадрат", "□"), ("треугольник", "△")]
    uk_shapes = [("коло", "о"), ("квадрат", "□"), ("трикутник", "△")]
    ```
    This causes the Cyrillic letter `о` to appear in answer keys instead of proper symbols like `○` or descriptive names like `"коло"`.

### 3. Is there protection against placeholder words?
Yes. `core/quality_gate.py` contains `check_placeholder_words()` which flags generic terms like `word`, `line`, `shape`, `digit` and repeated characters like `ssss+`.

### 4. Is there an empty answer check?
Yes. `core/quality_gate.py` contains `check_empty_answers()` and `check_answer_count()`. It outputs warnings for empty values in the answer blocks.

### 5. Is there a cover theme match check?
Yes. `core/quality_gate.py` has `check_theme_mismatch()` which compares display names from the lexicon to the worksheet's main title.

### 6. Are there real thematic words?
Yes. `core/topic_lexicon.py` contains lists of words for themes like "animals", "dinosaurs", "space", "underwater", etc.

### 7. Is there a `commercial_score`?
Yes. `compute_commercial_score()` in `core/quality_gate.py` ranks the worksheet out of 100 points:
*   Language Correctness: 25 points.
*   No Placeholders: 20 points.
*   Topic Presence: 15 points.
*   Instruction Variety: 15 points.
*   Answers Present: 15 points.
*   No Empty/Overloaded Pages: 10 points.

### 8. Is there a hard fail block?
**No**. While `run_quality_gate` outputs `passed = False` if `hard_fails` exist, `core/generator.py` **does not act on this flag**. It writes the JSON and generates the PDF regardless of failures, only printing warnings to the application log. The pipeline does not halt on hard quality gates.
