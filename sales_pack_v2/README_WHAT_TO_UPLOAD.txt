## 3. Telegram — рассылка (с прямой ссылкой)

ОТКРОЙ product_page.html в браузере — это визитка для клиентов

Как сделать ссылку из Telegram на OLX:
1. Опубликуй объявление на OLX
2. Скопируй ссылку на объявление (например https://www.olx.ua/...)
3. Открой product_page.html → найди "Перейти на OLX" → замени ссылку
4. Отправляй в Telegram ссылку на объявление + ссылку на твой Telegram

Как сделать прямую ссылку на Telegram:
1. Зайди в Telegram → Settings → Username → установи username (например @studypack_ai)
2. Ссылка будет: https://t.me/studypack_ai
3. Пропиши её в product_page.html (замени YOUR_TELEGRAM)

Шаблон сообщения для рассылки:

## 5. Как сделать product_page.html ссылкой для Telegram

Вариант A: GitHub Pages (бесплатно)
1. Зарегистрируйся на github.com
2. Создай репозиторий studypack-landing
3. Залей туда product_page.html + папку screenshots/
4. Зайди в Settings → Pages → выбери main branch → Сохрани
5. Получи ссылку: https://твой-ник.github.io/studypack-landing/
6. Эту ссылку можно вставлять в Telegram

Вариант B: Netlify (ещё проще)
1. Зайди на netlify.com
2. Перетащи папку с HTML и screenshots на страницу
3. Получи ссылку: https://random-name.netlify.app

## 6. Важно

- Продаёшь услугу: "Сделаю индивидуальный PDF-набор заданий"
- Не продаёшь программу: "Моя программа генерирует PDF"
- Никаких технических терминов (AI, нейросеть, генератор, OpenRouter, JSON)
- Первые деньги принесёт не интерфейс, а объявление + переписка
