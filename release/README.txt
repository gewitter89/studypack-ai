StudyPack AI - Генератор развивающих заданий для детей
======================================================

StudyPack AI - это интеллектуальное десктопное приложение для автоматического
создания обучающих рабочих листов (воркбуков) и карточек для детей 5-10 лет.

Быстрый старт:
--------------
1. Запустите приложение с помощью файла `StudyPack AI.exe`.
2. При первом запуске откройте вкладку «Настройки» и укажите ваш API-ключ OpenRouter
   (или настройте `.env` файл вручную на основе шаблона `.env.example`).
3. Перейдите на вкладку «Создать набор», выберите тему, возраст ребенка, количество страниц
   и нажмите кнопку «Сгенерировать пакет».
4. Готовый PDF-файл будет автоматически открыт и сохранен в папке `output/` рядом с программой.

Примеры:
--------
В папке `examples/` вы найдете готовые примеры сгенерированных рабочих листов
в формате PDF, а также конфигурации в формате JSON, которые можно импортировать
в приложении для повторной генерации или редактирования.
